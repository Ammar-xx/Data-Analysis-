# 📊 Python Data Analysis

This repository contains a collection of Python programs covering the fundamentals of **data analysis**, **data preprocessing**, and **data visualization** using popular Python libraries. It is intended for students and beginners who want to learn practical data analysis techniques through hands-on examples.

The project includes topics such as:

- **Pandas Basics**
  - Creating and manipulating DataFrames
  - Data inspection and exploration
  - Indexing and slicing
  - Data selection with `loc` and `iloc`
  - Merging DataFrames
  - Summary statistics

- **Data Preparation**
  - Handling missing values
  - Data imputation
  - Removing duplicate records
  - Data parsing and cleaning
  - Regular expressions and datetime conversion
  - Visualizing missing data

- **Data Visualization**
  - Creating plots with Matplotlib
  - Statistical visualizations with Seaborn
  - Multiple chart types for exploratory data analysis

The repository also includes sample datasets to practice data cleaning, transformation, and visualization techniques.

## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🎯 Purpose

The goal of this repository is to provide practical examples of data analysis workflows, from importing and cleaning datasets to exploring and visualizing data. It serves as a learning resource for anyone interested in Python-based data analytics and exploratory data analysis (EDA).
